# java-backend-roadmap

This repo is the single, evolving codebase for a 5-phase Java backend roadmap (Aug 2026 → Jun 2029), tracked publicly as the primary discipline mechanism for the plan. It starts as a small CLI console app in Phase 1 and grows into a tested, containerized Spring Boot service by Phase 4 — no restarts, one project deepened over time. Commits here are the real record: lecture practice code, DSA-in-Java solutions, and the milestones from each phase, pushed as they happen rather than polished after the fact.
